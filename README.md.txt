# 🎂 Birthday Surprise

A small birthday website I made by hand, just for one person. 💗

## How it flows

1. `index.html` – "Ready for your surprise?" (YES / NO)
2. `flowers.html` – flowers and a little message, ending with an envelope
3. `letter.html` – the letter, typed out sheet by sheet
4. `wish.html` – the final wish
5. `video.html` – a video with a song
6. `ending.html` – the ending

## Run it

Download the folder and open `index.html` in a browser. Keep all the files together
in one folder, since each page opens the next one.

## Made with

Plain HTML, CSS and JavaScript. No frameworks, no build step.
